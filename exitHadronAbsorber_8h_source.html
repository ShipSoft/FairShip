70 // Hand the buffered clones of a splitting decay to the stack popper. They

72 // designated as their carrier and must not be stopped before it steps.

108 // Upper bound on the clone buffer, in both splitting modes. Per-step
109 // splitting is the pathological case: the buffer grows by
110 // fIntermediateNsplits on every qualifying step and is only drained in
111 // PreTrack(), so a bad split count could make it grow without bound within a
112 // single track. ~25k TrackBuffer records is about 2.5 MB, far above what any
113 // sane configuration reaches. Set via --max-split-buffer.
114 // This is a hard bound: ProcessHits() stops accepting per-step clones early
115 // enough to leave room for the fNsplits endpoint clones PostTrack() appends,
116 // and Initialize() rejects a cap that fNsplits alone would exceed.
117 std::size_t fMaxSplitBuffer = 25'000;
118 // Upper bound on the projected event size: the stack size plus
119 // kShowerSafetyFactor entries for every pending clone. With the defaults this
120 // is the cap that stops per-step splitting, at about 10k pending clones.
121 // Set via --max-event-size.
