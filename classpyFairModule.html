std::vector< std::string > pyFairModule::SensitiveVolumeNames ( const std::string & module = "")
static

Names of the volumes that the modules of this run registered as sensitive so far, as FairDetector::Initialize() looks them up in the geometry given to Geant4 (without a "#" copy suffix). Compiled, because the list is thread_local, which the interpreter cannot reach reliably. With a module name, only the volumes that module registered.
