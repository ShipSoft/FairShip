Detailed Description

Fitted track from the ACTS straw tracker fit, in the SHiP frame.

The state is taken at the first measurement of the track. Positions are in cm, momenta in GeV. The covariance is the 6x6 matrix of (x, y, z, px, py, pz), stored as its upper triangle in row-major order, so the variances of px, py and pz are elements 15, 18 and 20.

The class does not depend on ACTS, so reco files can be read without it.

Extrapolate the track along a straight line to the plane at z (cm).

The fitted state is taken at the first measurement, so this is only accurate where the field between that point and z can be neglected. Returns false if the track is parallel to the plane.
