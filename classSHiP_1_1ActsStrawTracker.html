Detailed Description

Straw tracker track and vertex fitting with ACTS.

Fits track candidates from pattern recognition (or MC truth) with the ACTS Kalman filter, fits vertices with the Billoir vertex fitter and extrapolates fitted tracks to arbitrary planes. All inputs and outputs are in the SHiP frame (cm, GeV); ACTS is an implementation detail.

Usage per event: ClearEvent(), AddMeasurement() for each straw hit, then FitTrack() for each candidate, then GetTrack()/FitVertex()/DistanceToHit().
