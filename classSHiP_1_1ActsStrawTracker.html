Detailed Description

Straw tracker track and vertex fitting with ACTS.

Finds tracks with its own pattern recognition (StrawPatRec), or fits track candidates from another pattern recognition (or MC truth), with the ACTS Kalman filter; the left/right ambiguity of each straw hit is resolved in the fit. Also fits vertices with the Billoir vertex fitter and extrapolates fitted tracks to arbitrary planes. All inputs and outputs are in the SHiP frame (cm, GeV); ACTS is an implementation detail.

Usage per event: ClearEvent(), AddMeasurement() for each straw hit, then FindTracks() or FitCandidate() for each candidate, then GetTrack()/FitVertex()/DistanceToHit().
