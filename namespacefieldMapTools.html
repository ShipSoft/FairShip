Detailed Description

Helpers for reading, validating and repacking FairShip magnetic field maps.

A FairShip ROOT field map holds two trees. ``Range`` has a single entry with
the coordinate limits and bin widths (cm), and ``Data`` has ``Nx*Ny*Nz``
entries with the field components (Tesla), optionally accompanied by the node
coordinates.

``ShipBFieldMap`` reads ``Data`` sequentially and only imposes the grid
structure at lookup time, through ``index = (iX*Ny + iY)*Nz + iZ``: z is
increased first, then y, then x. Nothing in the file states the ordering, so a
map written in a different order is read transposed. When ``Nx == Ny`` and the
x and y ranges agree, even the entry count still matches and the mistake is
silent. The functions here make the ordering checkable, from both the stored
coordinates and from the field itself.

233def core_slices(rng, xy_fraction=0.3, z_fraction=0.25):
234 """Slices selecting the middle of the map, away from coils and yoke."""
235 xs, ys, zs = rng.axis_values()
236
237 def middle(values, fraction):
238 centre = 0.5 * (values[0] + values[-1])
239 half = fraction * 0.5 * (values[-1] - values[0])
240 (inside,) = np.nonzero(np.abs(values - centre) <= half)
241 if not inside.size:

243 # node nearest the centre so the caller gets a region, not an
244 # IndexError.

RMS of div B over the core of the map, and the local gradient scale.

A physical field has div B = 0, so an ordering that scrambles neighbouring
nodes shows up as a large residual. The gradient scale is the RMS of the
three diagonal derivatives, which is what the residual should be compared
against: it is the size div B would have if the derivatives did not cancel.

256def div_b_rms(field, rng, region=None):
257 """RMS of div B over the core of the map, and the local gradient scale.
258
259 A physical field has div B = 0, so an ordering that scrambles neighbouring
260 nodes shows up as a large residual. The gradient scale is the RMS of the
261 three diagonal derivatives, which is what the residual should be compared
262 against: it is the size div B would have if the derivatives did not cancel.
263 """
264 region = region or core_slices(rng)
265 terms = [np.gradient(field[..., axis], step, axis=axis) for axis, step in enumerate((rng.dx, rng.dy, rng.dz))]
266 dBx, dBy, dBz = (term[region] for term in terms)
267 divergence = dBx + dBy + dBz
268 scale = sum(float((term**2).mean()) for term in (dBx, dBy, dBz))
269 return float(np.sqrt((divergence**2).mean())), float(np.sqrt(scale))
