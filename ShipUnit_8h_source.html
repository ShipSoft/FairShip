5// Units of the FairShip C++ code, the same as python/shipunit.py and VMC:
6// lengths in cm, energies in GeV and magnetic fields in kilogauss. Times are
7// in ns here; VMC (gMC->TrackTime(), FairPrimaryGenerator::AddTrack) uses
8// seconds, so a time t in ns is t / ShipUnit::s in seconds. The exception is
9// geant4_vmc's gMC->ParticleLifeTime(), which returns the unconverted Geant4
10// value in ns.
11//
12// Multiply a value by its unit to express it in these units, and divide by a
13// unit to express a value in that unit. Angles are not defined here: TGeo
14// takes degrees, ROOT and the standard library radians. Use TMath for
15// physical constants.
16
